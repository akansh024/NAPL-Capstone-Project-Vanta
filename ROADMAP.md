# VANTA roadmap

## Implemented

- PostgreSQL assets, findings, imports, observations, and remediation-history schema.
- Dashboard, finding filters/details/status persistence, and Nmap XML observation import.
- Docker Compose, sample report, API/documentation, and parser tests.

## Partially implemented

- Remediation history is written but not yet exposed in the UI.
- Dashboard severity chart is intentionally simple for the initial demo.
- Import evidence is persisted but detailed observation browsing is the next UI increment.

## Planned next phase

- OWASP ZAP JSON ingestion.
- Cross-report correlation and deduplication.
- Complete remediation workflow and audit history.
- Exportable reports and explainable risk-priority scoring.
- Authentication and role-based access control.
- Optional Greenbone Community Edition integration.
